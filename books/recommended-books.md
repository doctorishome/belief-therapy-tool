# Recommended Books

Dr. Campbell's list of books to recommend on the belief cards.
Later, each book's Amazon Associates link will be added, and a "Recommended Books" box will be placed on the cards listed for it.

## How to add a book

1. On GitHub, open this file and click the pencil icon (Edit this file).
2. Copy the sample block at the bottom of this page (from `## Title` down to the last line) and paste it at the end.
3. Fill in each line after the colon. Leave a line as "(add later)" if you don't have it yet.
4. Click **Commit changes** to save.

**Cards:** list card numbers separated by commas, like this: SPR-106, BIO-061, INT-049.
(SPR = Spiritual/Religious, BIO = Biological/Physical, PSY = Psychological/Cognitive, INT = Interpersonal, SEC = Socioeconomic, SCU = Sociocultural, CORE = Core False Beliefs.)
You can also write a topic instead, such as "all pain and suffering cards," and the card numbers will be filled in for you.
